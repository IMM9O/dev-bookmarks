[![Check links](https://github.com/imm9o/my-bookmark/actions/workflows/links.yml/badge.svg)](https://github.com/imm9o/my-bookmark/actions/workflows/links.yml)

## Link check

A GitHub Actions workflow opens every link with [lychee](https://github.com/lycheeverse/lychee). It runs every Monday, on each push, and on each pull request. If a link is dead, the run fails and its log shows the link.

## Suggest a link

Open an issue or a pull request. Give the link, the page it belongs on, and one line about why it is useful.
